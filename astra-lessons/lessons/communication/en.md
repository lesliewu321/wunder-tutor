# English — Getting Around, People & Small Talk, Work

27 lessons; three supported age bands. Adults use the teen material. The work topic becomes school/teamwork for children.

Original authored material. Independent language-teacher review is pending. App audio uses the existing voice service; no publisher recordings are included.

Each lesson has a goal, guided practice, explicit model answers and an offline application task. Model answers are examples: the app does not grade free writing or every possible conversational reply.

### Ask and give directions (out-2)

**Goal:** Practise the question and response, then put a useful sentence in order.

**Teaching note:** Check the destination, direction and departure time separately. Practise the polite request as a whole phrase.

**Offline task:** Swap roles with a partner. Change one place, time or personal detail and repeat the exchange.

#### Little (supported practice)

1. Say: To the station, please.

2. Say: Go left.

3. Listen: teacher/app reads "To the station, please.". Choices: To the station, please. · Go left. · One ticket, please.. **Answer:** To the station, please.

4. Build the sentence using these chunks (shuffle before practice): To / the / station, / please.. **Model:** To the station, please.

5. Partner: Which way do I go?

   **Model reply:** Go left.

#### Junior

1. Say: Where would you like to go?

2. Say: I want to go to the station.

3. Say: Turn left at the school.

4. Listen: teacher/app reads "I want to go to the station.". Choices: I want to go to the station. · Turn left at the school. · I would like one ticket, please.. **Answer:** I want to go to the station.

5. Build the sentence using these chunks (shuffle before practice): I / want / to / go / to / the / station.. **Model:** I want to go to the station.

6. Partner: Which way do I go?

   **Model reply:** Turn left at the school.

#### Teen / adult

1. Say: Where would you like to go?

2. Say: I'm going to the station. Could you show me the way?

3. Say: Go straight, then turn right at the school.

4. Listen: teacher/app reads "I'm going to the station. Could you show me the way?". Choices: I'm going to the station. Could you show me the way? · Go straight, then turn right at the school. · I would like one return ticket, please.. **Answer:** I'm going to the station. Could you show me the way?

5. Build the sentence using these chunks (shuffle before practice): I'm / going / to / the / station. / Could / you / show / me / the / way?. **Model:** I'm going to the station. Could you show me the way?

6. Partner: Which way do I go?

   **Model reply:** Go straight, then turn right at the school.
