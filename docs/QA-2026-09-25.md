Web/application source: e237776. Android version 1.0.8, versionCode 9.
Production: https://app.wundertutor.com
Pages deployment: ff0cd171-ba51-4cdd-b7ed-94165c366ad5.

## Fixes

- Cantonese 唔該 now distinguishes thanking someone for help or service (and the separate use as please); 多謝 covers gifts and compliments. The old glosses misleadingly added a specific help/gift event to the utterance. Course content, conversations and all interface translations were updated without changing progress IDs. Reference: [CUHK Cantonese Grammar](https://www.cuhk.edu.hk/lin/cbrc/CantoneseGrammar/multimedia/20.htm).
- Conversation meanings now appear for English courses and younger learners. Filled missing conversation and Lab meanings across six translated interfaces. Seasonal lesson guides and Lab content are included in translation export/checks.
- Simplified UI guidance no longer rewrites Japanese text or quoted Traditional Cantonese practice examples; the Traditional script picker keeps its Traditional example.
- Rapid repeated onboarding consent clicks cannot create duplicate learners while microphone permission is pending.
- Foreground teacher failures in conversations, drills, dialogue, onboarding previews and spoken tips show translated feedback. Silent PCM recordings are refused; corrupt/silent server cache entries regenerate, and silent device cache entries refetch. Provider timeouts and network errors return controlled errors so configured backups can run.
- Preserves the latest per-course defaults and migration: Putonghua/Cantonese Qwen → Chirp; other courses Chirp → Azure. Explicit per-course overrides, including no backup and device-only choices, remain respected.
- Profile study-time units are translated in all seven interfaces.

## Artifacts and limits

- wunder-tutor-1.0.8-test.apk — signed debug APK for installation/testing, 5,201,152 bytes.
- wunder-tutor-1.0.8-unsigned.aab — unsigned Google Play bundle, 3,930,365 bytes. The owner must sign it with the upload key before Play upload. No store submission was made.
- SHA256SUMS.txt records both checksums.

No physical Android device was attached. Native microphone, camera, speaker output, Android permission prompts and installation were not hardware-tested. Browser audio completion and waveform checks do not certify accent/translation quality; exhaustive key/rendering coverage is not a native linguist review of every sentence. Email delivery and real account mutations were mocked. Synthetic audio and a synthetic image were used for live API checks; no children's recordings or credentials were committed.

Concurrent unfinished access-gating/library changes in the shared checkout were preserved and were not part of this clean release. Marketing and teacher-default changes already committed on main were integrated. The release does not claim that those unfinished changes were tested.

## Reproducing

Run scripts/gauntlet-server.mjs on its isolated port 5176, then gauntlet-onboarding.mjs, gauntlet-browser.mjs, gauntlet-flows.mjs and gauntlet-ui-final.mjs. PLAYWRIGHT_PACKAGE may name a local Playwright package.json. The live scripts gauntlet-live.mjs and gauntlet-live-client.mjs read the invite only from stdin; they do not store it. Reports and screenshots stay under the ignored .wrangler directory.
